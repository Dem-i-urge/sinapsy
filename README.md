# Синапсы — v0.1-draft · 16.10.2026

Панель-граф задач и проектов поверх Notion «Проекты» / «Задачи». Опубликована артефактом claude.ai «Синапсы»; артефакт — проекция, дом — этот репозиторий.

**Что делает.** Рисует выбранный кластер (надпроект → подпроекты → задачи) точками и связями. Подсвечивает богатые узлы (задача привязана к 2+ проектам — «богатый контекст» Плигина, см. `vault-psy/wiki/богатый-контекст.md`), просрочку и проекты без следующего шага («путь потерян»). Кнопки: «Готово» (с проверкой «мост сожжён?»), «В работу», «Связать ещё с проектом», «Добавить задачу». След последних шести переходов рисуется пунктиром (хранится в браузере зрителя).

**Истина одна — Notion.** Панель не держит своих данных: читает и пишет через коннектор Notion зрителя (`notion-query-data-sources`, `notion-update-page`, `notion-create-pages`). Второй базы нет.

**Модель внимания владельца (16.10.2026), из которой выросли правила:** вход — срочность > просьба человека > интерес; выход — внешний необратимый факт («мост сожжён»); прыжок — скука, особенно в ожидании; теряется чаще всего следующий шаг; связь задач = одно движение в двух проектах.

**Ограничения v0.1.** Задача, созданная панелью, не проходит стандарт `notion-task-project-hygiene` (иконка, сфера, проверка дубля) — только название, статус и проект. Статуса «Жду ответа» в базе нет: «стоянка ожидания» не реализована. Выборка — до 100 задач на кластер. Обкатка — строкой в «Обкатках» после первого живого прогона.
