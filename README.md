# Синапсы · v0.6-draft · 25.10.2026

Своя карта владельца: крупные точки по сферам, связи между ними, отметка «готово». Notion на карту не грузится — сверку с ним делает Архитектор по просьбе.

Дом — этот репозиторий. Артефакт claude.ai — проекция: опубликованная копия `sinapsy.html` с хранилищем `db`.

## Зачем так

v0.3 рисовала все незакрытые задачи и проекты из Notion. Карта получилась замусоренной: большую часть задач заводит Архитектор, это «техника», а не то, чем владелец думает о своей жизни. v0.4 переворачивает поток:

```
владелец ставит и отмечает точки на карте
        │  «Готово» → точка ждёт сверки
        ▼
«сверь карту» (Архитектору в чате)
        │  находит точку в Notion по ссылке или названию
        │  закрывает, если не закрыто (Статус Done + Дата выполнения)
        ▼
точка получает ✓  (или «?», если в Notion не нашлось)
```

## Что на карте

- **Кольцо сфер.** Сферы — секторы круга. Список и порядок правит владелец (кнопка «Сферы»), до 16. Цвет сферы следует из её места на кольце: непрерывный круговой спектр. Поменять порядок — сменятся и цвета.
- **Точка** — крупная единица: цель, узел, проект. Название, одна или несколько сфер, необязательная ссылка на Notion, заметка.
- **Место** точки запоминается, когда её перетащить. Новая точка встаёт в сектор своей сферы.
- **Два вида связей.**
  - *Зависимость* («Нужна сначала…» / «Открывает…»): без одной точки другая не сдвинется. Рисуется линией со стрелкой посередине. Пока предшественница в пути — линия пунктирная.
  - *Связь* («Связать»): смысловая, без порядка. Тонкая линия.
- **Заколдованный круг** — точки в пути, которые ждут друг друга (А ждёт Б, Б ждёт А, или по длинной цепочке). Карта круг не запрещает, а показывает: алая пунктирная петля, по которой бегает сигнал, и алое кольцо у каждой точки круга. Круги стоят первыми в обзоре. Выход — «Разрезать круг»: вы называете часть точки, которую можно сделать без остальных, она встаёт новой точкой, и всё в круге, что ждало разрезаемую точку, теперь ждёт её. Сделанная точка круг тоже разрывает.
- **Крепнущая связь.** Смысловая связь утолщается, когда обе её точки закрыты одна за другой: в пределах суток — сильно, трёх дней — средне, недели — слабо (порог `HEBB_DAYS` в коде). Это след совместной работы; в пульте у такой связи пометка «окрепла». Вес считается из дат закрытия и нигде не хранится.
- **Свет = сигнал.** Горит точка, у которой все зависимости сделаны: она доступна сейчас. Точка, которая ждёт незакрытую зависимость, тёмная, с цветным контуром. Сделанная гаснет.
- **Охват** — сколько сфер обслуживает точка: свои сферы плюс сферы всех связанных точек. Рисуется кольцом из дуг, по дуге на сферу, в цвет сферы. Охват 2+ = богатая точка (по Плигину, «богатый контекст»); охват 3+ у доступной точки пульсирует.
- **Связность** — сколько у точки связей и зависимостей всего. Чем больше, тем крупнее ядро.
- **Путь сигнала.** Клик по точке подсвечивает всё, что до неё, и всё, что она откроет; по стрелкам бегут импульсы, остальное гаснет. В пульте — «Путь сигнала сюда» по порядку, если цепочка длиннее одного шага.
- **«Куда дальше»** — доступные точки, отсортированные по тому, сколько других они откроют (по всей цепочке), затем по охвату.
- **«Готово»** спрашивает «Мост сожжён?»: готово то, что назад не отыграть. Если зависимость точки ещё в пути — предупреждает.
- **Масштаб** (колесо, щипок) раздвигает точки, но не растит их: значки, подписи и линии держат экранный размер. Масштаб сохраняется при любой правке; «Сбросить масштаб» возвращает 100%.
- **Подписи расступаются.** Каждая пробует четыре места вокруг точки. Порядок — по важности: выбранная, её путь, богатые доступные, доступные, ждущие, сделанные. Не нашла места — прячется и видна под курсором или после приближения.

## Оформление

«Нейронная ночь»: тёмное поле, свечение только у доступных точек и у пути сигнала. Один тёмный облик по выбору — метафора сигнала держится на темноте. Шрифты: Unbounded (заголовки), Golos Text (текст), JetBrains Mono (подписи и цифры).

## Хранилище

Возможность `db` артефакта. Читать и писать может владелец; Архитектор работает с ним через инструмент ArtifactData.

| Путь | Что |
|---|---|
| `nodes/<id>` | `title`, `spheres[]`, `links[]` (id точек, смысловые связи), `deps[]` (id точек, которые нужны сначала), `status` open/done, `doneAt`, `notion`, `note`, `sync` none/pending/synced/not_found, `syncNote`, `x`,`y` (доли радиуса от центра), `createdAt`, `updatedAt` |
| `meta/spheres` | `list[]` — сферы по часовой стрелке |

Связь хранится у одной из двух точек; карта считает её двусторонней. Зависимость хранится у зависимой точки (`deps`), направление — от предшественницы к ней.

## Процедура сверки (для Архитектора)

1. Прочитать `nodes`, где `sync = pending`.
2. Для каждой точки найти страницу Notion: по `notion`, иначе поиском по названию в «Задачах» и «Проектах».
3. Одна уверенная находка: если не Done — поставить Статус Done и Дату выполнения = `doneAt`; записать `sync = synced`, в `syncNote` — что сделано.
4. Ничего не найдено — `sync = not_found`, в `syncNote` — где искал. Несколько кандидатов — спросить владельца, ничего не закрывать.
5. Писать с `if_version` — чтобы не затереть правку, сделанную на карте в это же время.

## Ограничения

- Карта личная: доступна только владельцу, пока он сам не поделится.
- Сверка идёт только по просьбе (или по расписанию, если его завести). Сама страница в Notion не ходит — доступ снят намеренно.
- Нет истории изменений точки.
